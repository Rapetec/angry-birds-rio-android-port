# Angry Birds Rio for 64-bit Android

A port of **Angry Birds Rio 2.6.13** that runs on modern 64-bit-only Android phones, where the
original no longer works.

The game itself is unmodified. It runs fully offline, with no ads, no trackers and no real-money
purchases.

## Features

- Runs on current phones (Android 10+, ARM64).
- All episodes and levels.
- No ads and no tracking. The app has no internet permission.
- Mighty Eagle and Treasure Hunt are bought with in-game coins instead of real money.
- Ad-based rewards ("Get Free Coins!", the end-of-level bonus) give their coins without an ad.
- Online-only features stay on screen but do nothing.


The output is `AngryBirdsRio-arm64.apk`, for personal use.
